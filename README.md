# Atividade 07 - Qualidade do Produto de Software

Autor: Anderson Araujo Correia

## Objetivo
Praticar o controle de versão com Git e GitHub, registrando
alterações e utilizando branches no desenvolvimento de software.

## Ferramentas utilizadas
- Git
- GitHub
- Visual Studio Code

## Importância do versionamento
O controle de versão permite acompanhar o histórico das alterações,
recuperar versões anteriores e facilitar o trabalho em equipe.
Esses recursos contribuem para a organização e a manutenção do software.
